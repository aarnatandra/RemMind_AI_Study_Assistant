# Roadmap

## Foundation
- [x] Local-first dashboard and navigation
- [x] Study-task CRUD and completion tracking
- [x] Flashcard creation, review ratings and review dates
- [x] Notes CRUD and search
- [x] Self-reported quiz based on flashcards
- [x] In-browser PDF viewer
- [x] Offline keyword search over saved material
- [x] JSON backup and restore
- [x] Pure-function tests and GitHub Actions workflow

## Next iterations
- [ ] Add editing for tasks and flashcards with dedicated accessible dialogs
- [ ] Add subject-level filters and more detailed activity analytics
- [ ] Add CSV/Markdown import for notes and flashcards
- [ ] Add a shared topic/course model across tasks, cards and notes
- [ ] Evaluate a documented SM-2 or FSRS implementation with algorithm-specific tests
- [ ] Add actual PDF text extraction and page references
- [ ] Add an optional backend for authentication, encrypted cloud sync and AI services
- [ ] If adding a model provider, keep secrets server-side and document privacy/cost implications
- [ ] Add browser end-to-end tests and accessibility checks

## Integrity
Only mark items complete once the functionality has been implemented and verified. Do not backdate commits to imply prior development.
